## A little about me

I’m a software engineer and game designer with a master’s degree in software engineering. I like working close to the game: editors, file formats, runtime behavior, plugin APIs, UI systems, and the tools that connect them.

I care about making things understandable. If a tool changes something important, it should show you what changed and help you avoid breaking the next thing.

## What I care about

- Tools should tell you what they are doing.
- Important data should be hard to accidentally damage.
- Good documentation should explain the weird parts, not hide them.
- A useful open-source project should be easy to build, try, and contribute to.
